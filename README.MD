## ⚡ Getting Started

### 📋 Requirements

- A Windows computer.
- [Visual Studio](https://visualstudio.microsoft.com/) with the **.NET desktop development** workload, or a compatible .NET SDK.
- [Git](https://git-scm.com/) (optional).

### 1️⃣ Clone the Repository

Open Command Prompt or a terminal and run:

```bash
git clone https://github.com/pythondeveloper483/Learning-C-sharp-in-Class-12.git
cd Learning-C-sharp-in-Class-12
```

### 2️⃣ Open and Run

1. Open the project folder.
2. Open the `.sln` or `.csproj` file in Visual Studio, if available.
3. Build and run the program.
4. Modify the code and experiment with different inputs.

## 🧪 Example C# Program

Here is a simple C# program that adds two numbers:

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter the first number: ");
        double first = Convert.ToDouble(Console.ReadLine());

        Console.Write("Enter the second number: ");
        double second = Convert.ToDouble(Console.ReadLine());

        double sum = first + second;

        Console.WriteLine($"The sum is: {sum}");
    }
}
```
